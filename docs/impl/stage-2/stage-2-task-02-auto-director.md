# 任务02：低频 Auto 导演与注意力输入

> 历史实现记录：本文记录的 Auto 导演和指针注意力已由阶段3重构移除，不是当前运行时功能。

- 状态：已实现；纯逻辑与 timer 自动测试通过，视觉/手势留待人工验收。依赖任务01。共享契约见[阶段2开发规格](./stage-2-development-spec.md)。
- 目标：让角色大多数时间安静循环 Idle，偶尔做短动作；拖动态度输入影响视线和后续动作选择。
- 等待策略：常态每次随机等待12–24秒，45%概率触发动作；attention 下等待5–9秒、75%概率触发。动作后回 Idle，再开始下一次完整等待。权重：expressive/locomotion/settle = 72/8/20。
- 事件池排除 Death、持续循环 clip 和最近三段动作；settle 意味保持 Idle。expressive、locomotion 事件均按 clip 资产时长播放。随机源可注入；等待 timer 页面隐藏暂停并在恢复后按剩余时间继续。
- Auto 桌面左键拖动和触屏450ms长按拖动输入归一化注意力；右键旋转相机。具体 clip 选择后，左右键旋转和触屏单指旋转；双指捏合始终缩放。取消/失焦/切换 clip 释放输入。
- 完成条件：无人输入时 Idle 占多数时间且不会有无意义持续摆动；动作不连续重复，attention 只提高互动频率；Auto/clip source 切换和卸载无残留 timer；移动动作不造成舞台漂移。
- 验证：注入随机数测试等待范围、概率、权重与去重；假时钟测试隐藏暂停和清理；桌面/触屏手势逻辑测试；执行 `pnpm test`、`pnpm typecheck`、`pnpm lint`。
