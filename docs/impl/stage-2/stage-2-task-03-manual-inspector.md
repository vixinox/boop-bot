# 任务03：常驻动画与骨骼控制台

> 历史实现记录：本文中的 Auto 选择器已由阶段3重构移除；Inspector 的动画、骨骼和表情调试职责仍保留。

- 状态：已实现；自动检查通过，视觉可用性留待人工验收。依赖任务01，可与任务02并行。共享契约见[阶段2开发规格](./stage-2-development-spec.md)。
- 目标：提供可扫描的动画、骨骼和 morph 调试面板，不再要求用户切换全局 Manual 模式。
- 动画区 `Available clips` 首项为 Auto，后接模型全部14段有效 clip。选 Auto 表示导演运行；选具体 clip 停止导演并从头播放。Auto 时播放/暂停、时间轴、速度和循环控件禁用。
- 骨骼区提供完整 skin joint 目录、搜索/层级折叠、三轴角度滑块与数值、单项/全局复位；morph 区提供三项0..1权重。骨骼/morph 始终可用。
- 桌面固定420px常驻侧栏；窄屏继续使用舞台右上角圆形按钮打开 Sheet。分区滚动和焦点态可用。
- 完成条件：Auto 与所有 clip 可选，控件状态和播放来源一致；骨骼/morph 在所有来源下可调；窄屏无横向溢出。
- 验证：交互/状态测试、`pnpm test`、`pnpm typecheck`、`pnpm lint`、`pnpm format:check`；视觉布局由人工验收。
