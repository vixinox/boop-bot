# 阶段1任务03：快捷互动与表情控件

状态：已完成。实现为 `src/ui/CompanionControls.tsx`，导出 `CompanionControls`；快捷互动、休眠双态控制、持续气泡、独立权重滑块和空状态提示已交付。最终检查记录见[索引](../README.md)。下文保留执行范围与验收标准。

## 目标与完成结果

实现与三维场景无关的快捷互动、休眠/唤醒、回复气泡和三个表情权重滑块组件。完成后可由应用组合层直接挂载。

## 必读与决策来源

- 主规格：[stage-1-development-spec.md](./stage-1-development-spec.md)。固定回复生命周期、状态锁定、布局与范围以主规格为准。

## 范围与所有权

- 可写：`src/ui/**`。
- 不可写：store、`src/stage/**`、`src/App.tsx`、全局样式与文档。向集成负责人交付组件 API 和所需样式说明。
- 不实现对话文本框、规则识别、传感器、完整 Inspector、日志或 Three.js 内容。

## 输入与输出接口

- 输入：主规格中的 Zustand store；快捷按钮调用 `interact`，睡眠控制调用 `sleep`/`wake`，滑块调用 `setExpressionWeight`。
- 输出：提供明确的组合组件（建议 `CompanionControls`），从 store 展示情绪、回复气泡和当前权重，不维护重复的业务状态。
- 固定回复文案由 UI 层按 `headPat`、`praise`、`shake` 映射；每次事件传入 store 的对应互动操作。

## 行为验收

- 可触达摸头、夸奖、模拟摇晃三个清晰的快捷操作。
- 睡眠控制根据 `SLEEPY` 显示唤醒状态；休眠期间快捷互动禁用，唤醒控制可用。
- 气泡显示最新快捷回复，在后续互动前保持可读；睡眠/唤醒不清除它。
- `Angry`、`Surprised`、`Sad` 各有 0–1 控件并显示当前数值；不会把权重控件伪装成情绪选择。
- 桌面布局优先保证舞台可见，窄屏控制可换行或折叠，不发生文字/控件溢出或互相遮挡；控件具备可访问标签和键盘操作。
