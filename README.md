# Boop Bot

Boop Bot 是一个运行在浏览器中的桌面伴侣机器人原型，也提供动画、场景和行为调试工作台。项目使用 `public/RobotExpressive.glb` 展示可互动的 3D 角色；用户可以与角色聊天、触发反应，也可以让 AI 编排动画和编辑场景。

## 技术栈

- 应用：Vite、React、TypeScript、Tailwind CSS 和 shadcn 风格 UI 组件。
- 3D 与动画：Three.js、React Three Fiber、Drei；GSAP 用于界面动效。
- 状态：Zustand 管理动画/Inspector、场景数据和伴侣行为。
- 聊天服务：Node.js 代理 OpenAI Responses API；浏览器持有角色、场景和相机的运行时状态。

## 运行

要求 Node.js 22.12 或更高版本，并使用 pnpm。

```sh
pnpm install
pnpm dev
```

在另一个终端启动聊天 API：

```sh
pnpm server
```

聊天服务需要 `.env` 中的 `OPENAI_API_KEY`、`OPENAI_BASE_URL`、`OPENAI_MODEL` 和 `OPENAI_REASONING_EFFORT`；变量示例见 `.env.example`。不配置服务时，舞台和 Inspector 仍可本地使用。

## 功能

- 与角色聊天；本地中文规则会将对话映射为中性、开心、安慰或困倦反馈，并提供摸摸头、夸夸它和睡眠/唤醒快捷互动。
- 点按角色头部会得到现有 `Yes` 点头，点按躯干会短暂转向触点，点按手部会挥手；明确赞许/认可时 AI 可选择 `ThumbsUp`。拖动镜头不会触发触碰反应；不支持按住摸头。
- 初始与临时动作恢复动画为循环 `Idle`；行为状态由独立阶段/所有权运行时管理。用户移动镜头时角色会先转头、持续大角度变化后再转身。
- Inspector 可选择角色现有的14段动画 clip，并调节 GLB skin joints 的本地三轴旋转和 `Angry`、`Surprised`、`Sad` 三个表情 morph 权重。
- 聊天 AI 可使用现有片段创建有限动画时间线（最多12步、每步最多重复5次、总时长不超过30秒）；临时动作完成、取消或被打断后自动回到 Idle 或当前聊天阶段。
- 聊天 AI 也可编辑基础几何体和灯光，并调整当前相机；用户可旋转、平移、缩放和复位视角。
- 场景作品与对话历史只保存在当前页面会话，刷新后清除；服务端代理 Responses API，浏览器持有动画、场景和相机运行时状态。不接入摄像头或真实硬件。

行为系统、动画与场景工具均已实现并通过自动验证。角色继续使用现有 GLB 与有界程序化姿态；真实模型观感和复杂桌面/窄屏交互留待人工验收，验收脚本见[开发规格](./docs/impl/stage-4/stage-4-development-spec.md)。

## 开发复盘

- 开发工具：Codex，使用模型 `gpt-6.1-sol`；开发耗时：1天。
- 人负责拆分开发阶段、确定每阶段目标与关键决策，并在验收中判断实现是否符合预期：
  - 阶段1聚焦桌面伴侣舞台和基础互动，确定使用现有 GLB 角色，交付动画、表情、快捷互动、休眠/唤醒和适配桌面与窄屏的相机布局。
  - 阶段2聚焦动画与骨骼 Inspector，规划现有动画 clip、骨骼偏移和表情权重的调试能力。Auto 导演和指针注意力属于这一阶段的历史设计，之后在阶段3重构中移除，不代表当前行为。
  - 阶段3加入 AI 动画时间线、场景编辑和相机工具，并决定把模型可调用的动画与场景操作限制在有界、经过校验的接口内。
  - 阶段4完善伴侣行为生命周期、对话反馈、镜头注意力和头部/躯干/手部触碰反应；追加本地情绪路由与语义动作时继续使用现有模型资源，不扩展为任意骨骼控制。
- 人与 AI 按 Spec-Driven Workflow 共同构建开发规格和分阶段任务文档；AI 根据文档推进实现、自动验证，并同步实现规格、任务记录和项目说明。
- 人在验收和协作中持续调整方向：发现并反馈动画之间的冲突，推动明确动作所有权与恢复规则；遇到工具调用问题时反馈并完善工具协议和执行流程；同时明确 UI 组件库选型，以及 shadcn 组件安装、目录和仓库约束。

交付压缩包时不要包含 `node_modules`。演示录屏应为 1–2 分钟 MP4，展示 LLM 创建太阳系期间的情绪表达与角色语义动作协同，并覆盖睡眠/唤醒和快捷互动。
